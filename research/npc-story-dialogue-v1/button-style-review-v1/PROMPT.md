# Comparación de botones — prompt final

Herramienta: image_gen integrada, skill imagegen. Una lámina comparativa con cuatro familias, no cuatro assets instalables. Referencias: preview opaco V4 y las hojas locales de botones mágicos y paneles de pergamino indicadas en el prompt. Sin CLI ni API externa.

Use case: ui-mockup.
Asset type: ONE cohesive comparison board for four alternative button families in an existing fantasy RPG dialogue interface, for visual review only, not a production sprite sheet.
Input images: Image 1 is the current interface/context reference, use ONLY its charcoal floral-damask fill and angular antique-gold outer panel shape. Do not include Amber or the checkerboard scenery. Image 2 is a style reference for elegant fantasy ornaments, jewel-like purple/blue enamel and sculpted gold borders. Image 3 is a style reference for crafted parchment and aged metal UI parts. All three are references, not edit targets.
Create a polished high-resolution portrait board, approximately 1500x2100, with FOUR large comparison cards stacked vertically, equal dimensions and generous spacing, labelled A, B, C, D. Overall top heading in Spanish: "PROPUESTAS DE BOTONES"; small subtitle: "Comparación visual · No instaladas".
Each card has the SAME very dark floral-damask backdrop and SAME delicate angular gold outer border as the current dialogue UI, to compare buttons fairly. Keep the label and description above the frame. In each card show TWO long dialogue-choice buttons with these exact labels: "Quiero conocer este lugar." and "Solo pasaba a saludar."; beneath them a row of three compact utility buttons "Opaco", "Semi", "Transparente" and a small square X close button. The middle utility button can be subtly highlighted to demonstrate hover. Each family must be fully designed, cohesive and clearly different in silhouette, material, edge construction and ornament, not merely recolored. Do not reproduce the flat thin-outline current buttons.
A label: "A · Metal grabado". Smoky charcoal inset, substantial sculpted antique-bronze frame, modest bevel and relief, elegantly engraved corner knots, tiny gold side accents; premium grounded dark-fantasy style. Warm ivory text.
B label: "B · Pergamino antiguo". Warm aged ivory parchment inset, dark bronze carved brackets and corners, slightly irregular paper edge enclosed by a crafted metal frame, subtle dark ink lettering; historical fantasy material richness, readable clear center.
C label: "C · Cristal arcano". Deep midnight-violet enamel/crystal inset, sculpted silver and violet filigree around the ends, restrained sapphire inner edge-light and small gem/crest; magical night-sky style inspired by Image 2 but darker and calmer for the current UI. Pale ivory text. Do not add bright sparkles behind letters.
D label: "D · Oro ornamental". Near-black warm inset, flowing sculpted antique-gold foliage and elegant leaf-shaped ends, small centered crest above/below, organic graceful fantasy silhouette instead of angular techno borders. Warm ivory text; fine craftsmanship without excessive glow.
Button centers stay visually quiet and text is crisp, centered and easy to read. Design compact utility buttons as simplified members of each family; do not squeeze the full long-button decoration into tiny controls. Ensure all button silhouettes and ornaments fit fully inside their card and do not overlap. Real hand-painted game-UI material quality, soft controlled highlights, restrained rich depth, fully front-facing 2D interface graphics, no perspective. No additional text, no logos, no watermark, no characters, no illustration scenes. Existing panel background remains dark and neutral in all four cards.
