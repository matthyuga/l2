## Resultado práctico

Sí existen proyectos con peinados base para el creador de Interlude. La referencia más explícita es L2Famicom. Para ambas categorías juntas, Sanctuary demuestra el resultado buscado, pero usa High Five. La vía comercial identificada es L2MOD, con integración en el creador aún por confirmar.

No presentar páginas accesibles, contadores históricos ni un video como descarga disponible. Tampoco confundir un reemplazo de las caras A/B/C con caras adicionales D/E/F. Los diez accesorios instalados antes continúan siendo accesorios de inventario.

## Evidencia local y continuación

HTML guardado para Sanctuary y publicaciones de Rolo. `source-checks.json`, `more-source-checks.json` y `rolo-archive-search.json` documentan las comprobaciones HTTP y los enlaces encontrados. Algunos accesos de MaxCheaters desde requests devuelven 503; las publicaciones se leyeron mediante el navegador de investigación. Las páginas HTML son evidencia, no instrucciones para ejecutar.

Próximo paso para integrar: obtener los archivos de una publicación accesible, identificar si añade o reemplaza estilos/caras, comprobar todas las razas/sexos y adaptar los límites del creador y su validación de servidor según lo que efectivamente incluya el paquete. Nada de esto está confirmado por el título del mod.
