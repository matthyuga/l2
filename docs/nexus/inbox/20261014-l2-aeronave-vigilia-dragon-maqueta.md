# Nueva aeronave: Vigilia del Dragón, maqueta V1

Kevin retomó aeronave tras confirmar pisos/paredes Dust2. Pidió rediseño similar más épico y aportó imagen con barco oscuro/globo rojo/proa de dragón/faroles.

Se creó modelo NUEVO procedural en Blender5.0.1, sin importar mesh del original: E:/l2-local/research/airship-epic/Vigilia-del-Dragon-v1.blend. Nombre provisional Vigilia del Dragón;491 piezas y40.699 triángulos evaluados. Casco oscuro/bronce, globo carmesí panelado/sello dragón, mascarón dragón, faroles, cabina/timón elevado, cubierta central despejada, bancos, jarcias, motores con hélices. Tres renders vista-principal/cubierta/lateral y script reproducible build_epic.py; README detalla estado.

**No instalada en L2. No se tocaron aeronave original, muelle, Dust2 ni servidor.** Falta bake/UV/export optimizado, escala/holguras con jugador, colisiones/geodata y carga nativa. No tiene NPCs, animación, capacidad definida ni movimiento de transporte. Emisiones/luces son de render, no sistemas L2 implementados. No afirmar jugabilidad/movilidad por tener la maqueta. Launcher ABRIR-VIGILIA-DEL-DRAGON.cmd abre con Blender5 portátil, para evitar Blender3.5 antiguo.
