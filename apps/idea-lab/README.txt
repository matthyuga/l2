LABORATORIO DE IDEAS L2 — PORTÁTIL
==================================

Abrir:
  1-ABRIR-LAB-IDEAS.cmd

Cerrar:
  2-CERRAR-LAB-IDEAS.cmd

Dirección local:
  http://127.0.0.1:3212/

No requiere Internet, Node, Java, MariaDB ni instalación. Usa PowerShell incluido
en Windows y abre Edge, Chrome o Brave en modo privado con un perfil guardado en
este mismo disco.

Los datos se guardan únicamente en:
  data\workspace.json

Cada guardado automático crea una copia recuperable en:
  data\backups

El botón "Copia en el disco" crea además una copia manual. Las conversaciones de
"docs chatsgpt" se leen directamente desde el disco y nunca se modifican.

Para retirarlo de una PC ajena, cierra la ventana privada y ejecuta el acceso de
cierre. El Lab no usa cookies ni localStorage y dirige su perfil de navegador al
disco portátil. Windows o la red de una empresa todavía podrían conservar registros
técnicos de que se ejecutó un navegador; no guardan el contenido del proyecto por
decisión del Lab.
