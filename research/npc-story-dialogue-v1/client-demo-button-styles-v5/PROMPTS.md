# Producción de botones — cuatro familias

Herramienta: image_gen integrada, skill imagegen. Una llamada independiente por familia. Referencia compartida: button-style-review-v1/comparacion-botones.png. Salidas originales guardadas en sources/A.png, B.png, C.png y D.png. Fondo transparente real. Sin CLI ni API externa.

Las hojas se recortan por celdas y se adaptan con extremos preservados; las etiquetas se agregan a resolución nativa. Los tres estados de cada familia provienen de sus respectivas filas generadas.

## Familia A

Use case: ui-mockup. Asset type: ONE production game UI sprite sheet for button family A. The attached comparison board is a STYLE REFERENCE ONLY; reproduce only the requested family, no board or background. A / Metal grabado: exactly the charcoal-and-antique-bronze style of section A of the reference. Substantial sculpted bronze surround, smoky dark inset, engraved corner knots and little diamond side ornaments. Warm understated aged metal, not flat outlines.
Generate a clean front-facing 2D TRANSPARENT PNG sprite sheet, wide canvas about 1536x768, with exactly NINE separate blank controls arranged in a very strict 3 rows by 3 columns grid. No words, letters, numbers, state captions or X symbols anywhere.
Rows: row 1 NORMAL idle state; row 2 HOVER state with brighter controlled frame/material highlights; row 3 PRESSED state with inset/deeper center and slightly subdued highlights. Same silhouettes and geometry across the three states.
Columns: left column spans 0-68% of canvas width and contains one very wide horizontal dialogue-choice button per row, about 10:1 width to height; middle column spans 70-88% and contains one compact horizontal utility-button frame per row, about 3:1 width to height, simplified ornaments; right column spans 90-100% and contains one small square close-button frame per row, simplified corner ornaments with empty center. All controls must stay fully inside their own cell and not touch another cell. Each row occupies one third of canvas height; center all controls vertically inside their cells. Large transparent gutters between rows. Long buttons should be the same height as utility buttons, with the square frame at approximately that height too. Don't add a panel, backdrop, shadow rectangle, labels, text, characters or sample UI. No extra loose ornaments or sparkle particles. The transparent alpha should follow the outside contour; all interiors of the buttons themselves are opaque (especially the dark inset or parchment). Pixel-art is not desired. Rich hand-painted fantasy-game UI craftsmanship, crisp edges, readable quiet center, symmetrical aligned endcaps. Match the material and shape language of the chosen reference family closely.
